# Microcomputer Operating Systems

## Overview

This section documents hands-on lab experience completed as part of my Microcomputer Operating Systems coursework.

The labs provided practical experience with Windows and Linux operating systems, hardware and driver troubleshooting, system administration, storage management, virtualization, Windows Server, networking, and technical support tools.

These projects helped me develop skills applicable to entry-level IT Help Desk, Desktop Support, and Technical Support positions.
